Nowshera Family Clinic

A professional clinic appointment management system designed for a private family clinic in Nowshera, Khyber Pakhtunkhwa, Pakistan.

Overview

Nowshera Family Clinic is a web-based appointment management system that helps patients view available doctors, register and log in, and request appointments online. The system also provides a structured way to manage doctors, patients, and appointments through a centralized database.

The project is designed to reduce the dependency on manual phone calls, WhatsApp messages, and register-based appointment management.

Features

* Patient registration and login
* Patient dashboard
* Doctor profiles and specialties
* Doctor availability
* Online appointment booking
* Appointment management
* Patient profile management
* Supabase authentication
* Supabase database integration
* Responsive design for desktop and mobile devices

Technology Stack

* React
* JavaScript / TypeScript
* Supabase
* HTML
* CSS

Database

Supabase is used for authentication and database management.

The main database tables include:

* profiles — stores patient profile information
* doctors — stores doctor information and availability
* appointments — stores patient appointment requests and booking information

Appointment System

Patients can:

1. Create an account
2. Log in securely
3. View available doctors
4. Select a doctor
5. Enter appointment details
6. Submit an appointment request
7. View their appointment information

Project Purpose

The purpose of this project is to demonstrate a modern digital clinic appointment system that can help organize patient and doctor information and simplify the appointment process for a local private clinic.
